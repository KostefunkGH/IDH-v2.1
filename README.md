Итак, если вы так и не додумались, как запустить сайт, то вот инструкция:

////////////////Инструкция по скачиванию и запуску//////////////////////
1. Нажмите на этом сайте (как перешли по ссылке) на зелёную кнопку code, а затем нажмите "Скачать zip архив".
2. Дождаться загрузки
3. Распакуйте архив
4. Найдите в распакованной папке файл index.html и запустите его

Как открыть карту: нажимаете соответствующую кнопку во вкладке на сайте и кликните на файл map.png

Надеюсь, вы достаточно негуманитарии, чтобы понять инструкцию. Удачи!
